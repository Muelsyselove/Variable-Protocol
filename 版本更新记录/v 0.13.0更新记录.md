# v 0.13.0 更新记录

桌宠状态系统上线：接入用户生成的10状态立绘，桌宠随战况与饱食度实时变换表情。

## 新增

- 桌宠状态机（`data/pets.js`）：10 种状态——常态/高兴/沮丧/疑问/认真/思索/饥饿/哭泣/晕倒/傲娇，每种状态绑定专属Q版立绘（用户提供，共10张 + 全身立绘1张）。状态优先级：临时闪光（点击/胜负/AI决策）> 作战认真 > 等待玩家操作疑问 > 战败沮丧 > 饱食度分层（≤30饥饿 / ≤15哭泣 / =0晕倒）。
- 全局桌宠浮标（`ui/petOverlay.js`）：屏幕右下角常驻Q版桌宠（72px，小窗模式52px），随状态机实时换图，1.5秒轮询驱动闪光回落与饱食度衰减；点击触发傲娇表情与台词气泡；主菜单自动隐藏（由专属大展示位承担）。
- 状态触发规则：
  - 待机（主菜单/行动线/设置/桌宠终端）→ 常态（或饱食度分层状态）
  - 作战胜利 → 高兴（4秒闪光，战后返回界面可见）
  - 作战失败 → 沮丧（5秒闪光；结算屏基础状态亦为沮丧）
  - 需要玩家操作（事件/商店/奖励关/战斗内重抽决策）→ 疑问
  - 作战中（战斗界面）→ 认真
  - AI智慧代理决策（事件/奖励关/BOSS掉落）→ 思索（8秒闪光）
  - 饱食度 ≤30 → 饥饿；≤15 → 哭泣；=0 → 晕倒（浮标停止漂浮并变灰）
  - 鼠标点击桌宠（浮标/主菜单大图/小窗中枢）→ 傲娇（3秒，附台词气泡）
- 状态专属台词：为全部10种状态补充原创台词库（傲娇/哭泣/晕倒/思索/疑问/沮丧等）。
- 状态名展示：主菜单桌宠标签、小窗中枢悬停、桌宠终端当前桌宠区均显示当前状态名。

## 调整

- 主菜单桌宠：图片改为状态驱动（原固定常态图+「饿了」文字标记），点击互动升级为傲娇表情+台词+音效，3秒后自动回落。
- 小窗中枢桌宠：图片改为状态驱动（战后返回中枢显示高兴/沮丧，平时按饱食度分层）；饥饿台词分层细化（≤15哭泣台词、=0晕倒台词）。
- 桌宠终端当前桌宠展示区：图片与状态名同步状态机。
- 旧版通用动漫立绘（magical girl/chibi 缓存图）全部替换为用户生成的缪尔赛思专属立绘。
