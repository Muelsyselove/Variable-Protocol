# v 1.3.1 更新记录

> 修复部分机器上应用内检查更新失败的问题。

## 修复

### 应用内检查更新失败（无法验证证书 / 不走系统代理）

- 现象：设置页「检查更新」提示"检查失败"，错误信息为证书校验失败（unable to verify the first certificate）或连接失败。
- 根因：主进程使用 Node 原生 `fetch`（undici）请求 GitHub API，它使用 Node 内置 CA 证书包、不读取 Windows 系统证书库，也不走系统代理；在装有自定义根 CA（安全软件 / 代理拦截 TLS）的机器上，GitHub 连接的证书无法通过校验。
- 修复：改用 Electron `net.fetch`，走 Chromium 网络栈，自动使用系统证书库与系统代理设置。
