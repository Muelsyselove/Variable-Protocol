# v 2.1.0 更新记录

> 账号体系与启动流程重构：游戏启动前登录/注册（自动分配 16 位数字账号）、4K 开屏大字 Logo、
> 主界面公告系统、设置界面分类化、云端存档全自动同步。

## 新增

### 登录界面（游戏启动前的账号门）

- 开屏结束后进入登录界面：从未登录自动展示「登录 / 注册」表单；已登录展示掩码游戏账号（仅显示前三位与后三位数字，中间以 * 替代，如 `123**********456`）与「开始游戏」按钮，并提供「切换账号」；
- 注册填写用户名（2~24 位纯英文字母）与密码（不低于 8 位且同时包含字母和数字），系统自动分配 16 位纯数字游戏账号；注册成功完整展示账号号一次并提供「复制账号号」（登录使用账号号，请玩家牢记）；
- 登录使用 16 位数字账号号；服务器兼容旧版用户名登录（旧账号启动时已自动补发账号号，可经管理端查询）；
- 服务器不可达或未配置时可「离线开始」直接进入游戏（云功能停用，下次启动仍可登录）。

### 账号操作（设置 → 账号分类）

- 修改密码：验证原密码后更换，成功后本机登录凭据自动更新（旧登录令牌全部失效）；
- 注销账号：输入密码确认并二次弹窗确认后**永久删除**账号与云端存档（不可恢复），本地档案保留但不再同步；
- 登出：清除本机登录状态；
- 云存档手动上传 / 恢复保留（恢复前自动本地备份）。

### 云端存档全自动同步

- 开始游戏时智能拉取：仅当云端存档比本地新时自动恢复（本地自动备份），离线游玩的进度不会被旧云端数据覆盖；
- 退出游戏时自动上传本地玩家档案（限时 8 秒，无论成败不阻碍退出；离线 / 未登录直接退出）。

### 主界面公告系统

- 主界面左上角新增「公告」按钮：公告自动从服务器读取（管理员经 `admin.mjs announce-add` 发布，发布后免重启即时生效）；
- 进入主界面时有未读公告自动弹窗展示（看过的不再重复弹，已读记录存于玩家档案），公告按钮随时可回看全部；
- 公告弹窗为终端风列表（标题 / 日期 / 正文），未读时公告按钮点亮红点。

### 通用弹窗组件

- 新增终端风格弹窗组件（角括号面板 + 遮罩，支持确认/危险操作/内容列表），供公告展示、退出终端确认、注销账号确认、行动档案占位提示等使用；
- 弹窗遮罩自标题栏下方开始：任何弹窗打开时窗口的最小化 / 最大化 / 关闭按钮均保持可用。

## 调整

- **开屏界面**：改为 MCP 生成的 4K 透明大字 Logo（`resources/game/images/logo.png`，原生透明底生成后本地放大到 3840×2160）：Logo **沿垂直于屏幕的轴线从高处坠落到屏幕面**（高处贴近观者显大、坠落即远离观者逐渐缩小 + 落地压扁 + 小幅回弹），**落到屏幕面的瞬间四色光环（绿/青/紫/琥珀）如涟漪般自 Logo 中心依次扩散**；坠落动画结束 0.5 秒后才开始检查更新（资源与存档加载仍从启动即刻并行执行）；更新完成后 **Logo 不消失再出现，而是平滑飞行至登录页目标位无缝交接**，登录面板、离线开始、页脚等组件在飞行途中分层淡入，副标题随 Logo 到位浮现；图片缺失时自动回落文字标题（同样带坠落动画）；开屏与登录界面均不遮挡标题栏按钮；
- **主界面**：左上角不再展示游戏名称，改为「设置」（有新版本时点亮红点）与「公告」按钮；原「系统设置」导航按钮改为「行动档案」（成就系统，占位按钮，点击提示制作中）；「退出终端」迁移至设置界面底部（点击需弹窗确认），原位置改为彩蛋按钮「啥也没有」（点击弹窗「都说了啥也没有」）；
- **设置界面分类化**：顶部切换分类——账号（账号状态 / 云同步 / 修改密码 / 登出 / 注销）｜AI 与自动协议（AI 接口 / 方案池 / 进化模式）｜通用（声音 / 小窗模式 / 数据目录）｜版本与资源（版本与更新 / 资源版本）；
- **任何界面不再展示服务器地址**：账号状态接口不再向渲染层返回服务器地址；
- 服务端注册规则：用户名仅允许 2~24 位纯英文字母（登录仍兼容旧版用户名）；密码策略提升为不低于 8 位且同时包含字母和数字（客户端执行）。

## 修复

- 修复旧版本本机已登录会话缺少账号号字段的显示问题：登录界面与设置页会自动向服务器核对补全（新增 `GET /api/auth/me`）。

## 其他

- 服务端新增接口：`GET /api/auth/me`（会话信息）、`PUT /api/auth/password`（修改密码）、`DELETE /api/auth/account`（注销账号）、`GET /api/announcements`（公告列表）；注册 / 登录响应新增 `account`（16 位数字账号号）；启动时为旧用户自动补发账号号；
- 管理 CLI 新增公告命令：`announce-add <标题> <内容或文件>` / `announce-list` / `announce-del <id>`；`user-list` 显示各用户账号号；
- 部署自检扩展至 42 项（新增账号号分配 / 账号号登录 / 旧用户名兼容 / 改密 / 注销 / 公告全链路校验）；
- 资源包新增 Logo 图片（164 个文件），资源清单版本升至 2.1.0；
- 版本号 v2.0.0 → v2.1.0（功能性更新）。
