# v 2.2.0 更新记录

> 公告功能升级：服务器按分类存储公告（系统通知 / 游戏公告），公告旁新增邮件系统——
> 邮件可包含标题、发件人、正文与附件（算力币 / 生态口粮 / 桌宠），领取状态由服务端标记防重复发放。
> 账号位数由 16 位调整为 11 位（服务器账号已全部重置）。

## 新增

### 公告分类（系统通知 / 游戏公告）

- 服务器按分类存储公告：`system` 系统通知（游戏版本更新、调整细节）、`game` 游戏公告（新增内容与后续更新前瞻）；
- 公告弹窗顶部新增分类标签页切换，未读时自动弹窗默认定位到含未读更多的分类；
- 旧版公告数据（无分类字段）自动归入系统通知；旧客户端忽略分类字段照常展示，保持向后兼容。

### 邮件系统

- 主界面公告按钮旁新增「邮件」按钮：邮件包含标题、发件人、正文、附件与日期；
- 附件类型：算力币、生态口粮、桌宠（直接入账玩家档案：算力币进钱包、口粮进桌宠仓库、桌宠解锁所有权）；
- 邮件列表点击进入详情弹窗，含附件时提供「领取附件」按钮，领取成功弹窗展示入账明细；
- 领取状态由服务端按账号标记（`claimed`），多设备 / 重装游戏不会重复发放；同一邮件重复领取会被拒绝（409）；
- 存在未领取附件的邮件时，邮件按钮点亮红点提醒（未登录 / 未配置服务器时邮件功能静默禁用，不影响游戏）；
- 邮件支持定向发送（指定用户）与全服发送（收件人 `all`），可设置过期天数，过期邮件在读取时自动清理；
- 每封邮件附件上限 8 个，正文与公告同样限 4000 字符。

## 调整

- 公告接口 `GET /api/announcements` 返回数据新增 `category` 字段，系统通知与游戏公告各保留最新 20 条（按 id 降序）；
- **账号位数由 16 位调整为 11 位**：注册自动分配的纯数字账号从 16 位改为 11 位（首位非 0），登录输入框、输入校验（11 位数字）与掩码展示同步调整；配合本次调整，服务器全部账号已清空重置（原数据已备份），旧注册账号不再保留，需要重新注册。

## 修复

- 修复注册成功后文案错误：提示语与按钮由「账号号」更正为「账号」（如「登录需使用账号，请牢记」「复制账号」）。

## 其他

- 服务端新增接口：`GET /api/mail`（当前用户邮件列表，Bearer 鉴权）、`POST /api/mail/claim`（领取邮件附件，服务端标记已领取）；
- 管理 CLI 公告命令升级：`announce-add <标题> <内容> [--category system|game]`（默认系统通知）、`announce-list` 显示分类；
- 管理 CLI 新增邮件命令：`mail-send <用户名|all> <标题> <发件人> <正文> [--attach coins:100 --attach food:5 --attach pet:<id>] [--expires <天数>]`、`mail-list`（含领取统计）、`mail-del <id>`；
- 部署自检扩展至 54 项（新增公告分类发布 / 读取校验、邮件定向与全服发送 / 附件清单 / 领取与重复领取拒绝 / 删除清理全链路校验）；
- 版本号 v2.1.0 → v2.2.0（功能性更新）。

## 服务器端部署说明

- 上传 `server/server.mjs`、`server/admin.mjs` 至服务器 `~/vp-server/`，执行 `sudo systemctl restart vp-server` 生效（已于 2026-09-15 部署）；
- 账号位数调整：服务器全部账号已清空（原 users.json / players.json 已备份为 `*.bak-*`），无数据迁移需求——旧 16 位账号已随清空一并移除，新注册自动分配 11 位账号。
