# v 0.3.0 更新记录

首个可运行原型：Electron + Three.js 工程搭建完成，全部核心系统实现并通过自动化验证，游戏从主菜单到战斗再到结算的完整局内流程可玩。

## 新增

### 工程骨架
- Electron 桌面工程：electron-vite 构建（主进程/预加载/渲染三层），npm 国内镜像配置。
- 主进程提供本地 JSON 存档接口（userData/saves），预加载脚本以 contextBridge 安全暴露。
- 渲染进程入口、屏幕路由（含屏幕清理钩子）、全局状态与存档管理（局内 run.json + 局外档案 profile.json）。

### 核心引擎（src/renderer/src/core，纯逻辑、可独立测试）
- rng：mulberry32 种子随机数，状态可序列化随存档持久化。
- attributes：属性计算器，四类修饰器（加算/乘算/终加/终乘）完整实现，含负向乘算统一加算、(1+Dt)<0 补正、数值范围钳制、计时修饰器推进、动态提供器（条件性效果）。
- damage：五类伤害类型公式（物理/法术/心理/真实/治疗），攻方穿透与守方属性上下文组装。
- dice：骰子池（独立实例、等概率抽取、上限、治疗骰禁入），点数缩放平缓曲线（0.5+点数/12）。
- judgment：伤判效果链，七类效果按既定优先级（不受伤→闪避→伤害修改→抵挡→过量治疗→反伤→反击）依次结算；护盾FIFO+屏障吸收；归零后检测类停止处理、反馈类继续；治疗管线含溢出转化。
- psychology：心理损伤累计（受损伤抵抗公式影响）、四类心理崩溃（瞬间心理伤害+各自惩罚）、崩溃期间封锁累计、麻痹充能模型（逐层消耗）。
- combat：五阶段回合状态机（回合开始→掷骰→先手→后手→回合结束），平局重掷、自动/手动重抽、空引用点数钳制、易碎/临时骰、事件总线钩子供能力与转译器接入、死亡检查与应急熔断复活。
- run：行动线推进（5层循环段+特殊节点轮换）、虚质生成（层数缩放、BOSS轮换与循环×1.5）、干员战斗规格构建（武器骰池+局内额外骰）、战斗衔接与胜利结算（通量/自动回复/快速迭代）。

### 内容数据（src/renderer/src/data，全部按设计文档数值落盘）
- 4干员、4武器、9普通虚质+3BOSS（能力全部实现）、23转译器（11普通+3核心+9高阶，钩子系统）、14种骰子定义、8特殊事件+奖励关三选一。

### 渲染与界面
- Three.js 骰子池渲染：骰面程序化贴图、类型配色、按点数分组排列、暗态显示、轮盘式掷骰扫光动画（减速停在结果骰上）。
- 8个屏幕：主菜单、干员/武器选择、行动线（节点条+核心槽+转译器清单）、战斗（双方面板/骰池3D/战斗记录/浮动数字/重抽决策/BOSS三选一/胜利结算）、商店（货架+刷新+出售）、事件、奖励关、结算。
- 终端美学视觉体系：磷光绿/琥珀/绯红配色、角括号面板、扫描线与网格背景、等宽字体数据展示、提示框系统。

### 测试
- test/smoke.mjs：36项断言覆盖属性计算、伤害公式、骰池概率（模拟验证P(6)=0.5）、节点序列、虚质生成与BOSS轮换、四组干员×武器整场战斗模拟、心理崩溃链路专项——全部通过。
- electron-vite 生产构建通过，应用启动验证通过（无运行时报错）。
