# v 0.22.0 更新记录

> 主界面布局参考明日方舟重构：左侧桌宠立绘 + 右上资源胶囊条 + 右侧阶梯块状按钮群。仅调整布局与视觉，全部菜单内容、功能与互动保持不变。

## 新增

- 主菜单顶部新增资源胶囊条（明日方舟右上资源栏式）：算力币 / 最高层数 / 出击 / 清除四项统计以「图标块 + 名称 + 数值」胶囊呈现，算力币数值保持琥珀色，位置移至窗口右上（标题栏下方）。
- 桌宠名片新增头像块：以桌宠当前状态 Q 版图作为头像，与名字、称号、状态并排成玩家卡式布局；饥饿 / 哭泣 / 晕倒警示态下头像框同步转为琥珀色。

## 调整

- 右侧导航按钮群重构为明日方舟式阶梯块状布局，六项内容与功能不变：
  - 「新的一局」为主打大块（116px 加高、大字号、宽字距、左侧 5px 粗色条强调，与常规块形成层级落差）。
  - 「继续行动」为右对齐中块（86% 宽）。
  - 「桌宠终端 / 档案图鉴」「系统设置 / 退出终端」为两行双列块，行内左右宽度比例交错（1.24:1 与 1:1.18）形成参差感。
  - 按钮紧贴堆叠（间距 9px）、平行四边形斜切、右下硬投影，呈现块面拼合质感。
  - 保留按钮入场滑入动画与逐项延迟。
- 按钮群整体 3D 跟随鼠标视差调平（rotateY 基准 -14° → -6°、rotateX 2.5° → 1.5°），适配阶梯布局不破坏块面感；立绘反向视差保留。
- 按钮 hover 效果改为左移 + 绿色高亮 + 双层投影；主按钮 hover 高亮增强。
- 分区注释更新为实际布局描述。

## 修复

- 修复「新的一局」主按钮纵向被压扁：按钮基础样式的 flex:1 在纵向堆叠中覆盖了高度设定，导致实际渲染仅约 31px（比常规按钮更矮）；现解除其 flex 拉伸，恢复 116px 主打块体量。
- 修复窄块按钮文字换行折断问题（「档案图鉴」「系统设置」等按钮文字不再折行）。
