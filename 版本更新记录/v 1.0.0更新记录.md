# v 1.0.0 更新记录（正式版）

> 首个正式版发布：推出 Windows 安装程序，游戏全部数据本地化存储于安装目录。

## 新增

### Windows 安装程序（正式发版）

- 新增 electron-builder + NSIS 安装器构建管线：`npm run dist` 一键产出 `VariableProtocol-Setup-1.0.0.exe`。
- 向导式安装：支持**自定义安装位置**；安装时可勾选是否创建**桌面快捷方式**；自动创建开始菜单快捷方式。
- 内置卸载程序（控制面板"变量协议 v1.0.0"可卸载）；卸载时保留 `data` 存档目录，存档不随卸载丢失，可手动清理。
- 任务栏 / 快捷方式 / 窗口图标统一使用 `resources/icon.ico`。

### 数据本地化存储

- 打包版启动时将 Electron userData 重定向至 `安装目录\data`：存档（`saves\profile.json`、`saves\run.json`）、Chromium 缓存与运行时状态全部写入安装位置，不再占用 `%APPDATA%` 等系统目录。
- 开发模式行为不变，仍使用默认 userData，避免缓存污染仓库目录。

## 调整

- 版本号由 v0.24.0 升级为 **v1.0.0**（正式版首位版本号启用）。
- 主菜单版本标识同步更新：`PROTOCOL TERMINAL v1.0.0`。

## 修复

- 无。

## 其他

- 冒烟测试 102 项全部通过，旧存档格式完全兼容（存档目录随 userData 迁移后读取逻辑不变）。
- 卸载与重装建议：重装到相同目录可继承原存档；如需彻底清理，卸载后手动删除安装目录下的 `data` 文件夹。
