# v 2.0.0 更新记录

> 架构级重构：游戏资源与游戏核心分离、玩家数据独立存储、全新开屏界面与自动更新、预留个人后台服务器接入。
> 本版本为破坏性重构（版本号升 a 位），游戏行为与数值与 v1.6.0 完全一致（两处历史遗留 bug 的修复除外，见「修复」）。

## 新增

### 开屏界面与自动更新

- 启动时在主窗口内显示开屏覆盖层（品牌标识、版本号、启动进度），与游戏界面同窗口无缝衔接，检查完成后淡出进入主菜单；
- 开屏阶段自动检查游戏更新（个人后台服务器优先，GitHub Releases 兜底），同时并行加载游戏资源与玩家存档，网络异常不阻塞进入游戏；
- 发现新版本时自动下载安装包到数据目录（`updates/`）并实时显示下载进度，完成后提供「立即安装」（运行安装包并退出）与「稍后再说」；
- 开发模式跳过自动下载，仅提示。

### 游戏资源与游戏核心分离

- 全部游戏资源（转译器 / 骰子 / 敌人 / 干员 / 武器 / 事件 / 桌宠定义与全部游戏图片，共 163 个文件）从程序内部移出到独立资源包 `resources/game/`（数据 JSON + 图片 + 版本清单 manifest）；
- 资源效果全面声明化：资源只声明 `{"fx":"效果名","params":{数值}}`，全部算法实现在游戏核心的效果注册表（fxRegistry）中——资源不再自带任何代码，扩展资源无需改动核心；
- 自定义 `game://` 协议加载资源；开发模式下直接修改资源 JSON 即时生效，无需重新构建；
- 安装包体积大幅缩减（程序与资源分离，资源可独立替换）；
- 设置页新增「资源版本」面板：显示当前资源版本与来源（安装基线 / 服务器更新），支持检查资源更新与一键修复（回退基线，不影响存档）。

### 个人后台服务器（生产版服务端 + 客户端接入）

- 内置后端服务客户端：玩家注册 / 登录 / 登出、玩家数据云存档（上传 / 恢复，恢复前自动本地备份）、资源版本更新、游戏核心更新查询；登录 / 注册仅传输密码的 SHA-256 摘要而非明文（HTTP 直连场景下防链路嗅探泄露玩家复用的密码，服务端无需感知、升级 HTTPS 后亦兼容）；
- 生产版服务端（`server/`，零依赖 Node ≥ 18，`npm run server` 启动）：scrypt 密码哈希 + Bearer 令牌鉴权（多设备）、注册/登录限流、请求体大小限制、静态文件断点续传（Range）、原子化 JSON 存储；
- 配套管理 CLI（`npm run server:admin`）：发布/移除资源版本、发布/移除核心安装包、查看版本、列出用户、重置密码、删除用户；
- 资源更新为增量同步：服务端按客户端当前资源版本计算差异，仅下发变更与新增文件（实测 163 文件资源包改动 1 个文件仅下发 1 个文件）；客户端以现有资源为基底复制 + 变更覆盖 + 移除清理 + 原子替换；客户端版本未知时自动回退全量；
- 核心更新支持从服务器下载：开屏自动下载优先走个人服务器（下载完成自动 sha256 校验，损坏即清理报错），服务器未发布时回落 GitHub Releases；
- 设置页「账号与云同步」面板新增注册（注册即自动登录）；
- 服务器地址仅存于本机 `%APPDATA%\variable-protocol\server.json`（不入仓库，模板见 `server.example.json`）；`server/data/`（用户与存档数据）同样不入库；
- 附部署自检脚本 `npm run server:selftest`（22 项端到端校验：注册/登录/鉴权/云存档/增量 diff/核心下发/断点续传）与本地 mock 服务器（`npm run mock-server`，开发工具不入版本记录）。

### 玩家数据独立存储

- 玩家档案引入版本化迁移链（`profileVersion`），为后续云同步与结构演进铺路；
- 桌宠存档 id 迁移机制升级：迁移记录写入存档（`pet.migrations`），同一条目只执行一次；
- 账号凭据独立存放于 `account.json`（不混入玩家档案，不会随云存档回传）；
- 存档写入接口白名单化：仅允许玩家档案与对局数据两个文件。

## 调整

- 存档清洗（读档时的桌宠数据整理）改为「仅当旧 id 已从桌宠定义表退役时才迁移」——判断依据始终来自当前资源包；
- 干员「偏移」「溢出」的特殊能力改经统一的资源效果通道声明（见下方修复说明，能力本身不变）；
- 数据目录切换时仅迁移存档，不复制资源覆盖层（覆盖层为可重建的缓存，服务器可重新推送）；
- 资源包带版本清单（manifest）：安装基线随安装包发布，服务器资源更新写入数据目录覆盖层，版本更高者优先生效；覆盖层损坏或版本不高于基线时自动回退基线，不删除磁盘内容。

## 修复

- **修复购买桌宠「缪尔赛思」后存档丢失的问题**：v1.6.0 的旧 id 迁移逻辑（muelsyse → luolian）在每次启动时无条件执行，而新「缪尔赛思」复用了旧 id，导致购买写入成功、下次启动即被当作旧数据迁走删除。现改为仅迁移已退役 id，购买后重启数据完整保留；
- **修复干员「偏移」「溢出」特殊能力不生效的问题**：其能力函数（ability）从未被战斗引擎调用，属于死代码——「相位重掷」与「过压写入」实际从未生效。现统一并入生效通道，能力描述与实现一致；
- **修复事件「冗余备份」满血时判断错误的问题**：原代码读取不存在的字段导致"生命值已满转化为 60 通量"分支永远不触发，现按实际最大生命正确判断。

## 其他

- 版本号 v1.6.0 → v2.0.0（破坏性重构，升 a 位）；
- 新增资源包 lint 校验并纳入 `npm test`：资源 JSON schema、效果引用完整性、图片存在性、骰池引用、id 唯一性、默认代理配置引用全量核对；规模断言采用动态校验（当前规模仅作防数据丢失下限，新增桌宠/转译器/干员/武器等内容无需修改测试）；
- 新增资源清单生成脚本 `npm run gen:manifest`（发版前运行，开发工具）；
- 旧存档升级到 v2.0.0 无需任何操作：读档时自动完成清洗与版本标记，宠物、算力币、方案池等全部保留。
