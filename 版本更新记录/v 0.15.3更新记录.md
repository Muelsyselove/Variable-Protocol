# v 0.15.3 更新记录

桌宠模式七项修复与增强：后台推进根因修复、点击穿透、拖动重写、菜单重构与静音/倍速/动画控制。

## 新增

- 桌宠右键菜单新控制项：
  - 静音/开启音效：直接开关游戏音效（写回存档，与系统设置联动）；
  - 战斗倍速：×1 → ×2 → ×4 循环切换（下一场战斗生效）；
  - 跳过动画：开/关切换（当前战斗立即生效）。
- 像素级点击穿透：桌宠立绘画布 alpha 命中检测——鼠标在桌宠像素上时窗口可交互，在透明区域/气泡时鼠标事件放行到底层窗口（setIgnoreMouseEvents + forward 悬停检测恢复）。桌宠周围区域不再挡住桌面点击。

## 调整

- 桌宠模式协议白名单：仅允许「自动代理」与「智慧代理」。右键菜单的协议列表只展示这两项；进入桌宠模式时若当前协议为其他（未启用/自动协议）自动升级为自动代理。
- 右键菜单重构为扁平布局：所有项目直接可见（含协议/桌宠分组标题），不再二级折叠；菜单高度超出窗口时内部滚动，位置由 JS 精确钳制在窗口内。

## 修复

- 桌宠模式游戏不推进（根因）：自动协议/未启用协议在事件、商店、奖励关、BOSS掉落等决策点等待手动操作，而桌宠模式下主窗口隐藏永远等不到输入——表现为战斗打完（有音效）后停在决策节点不再推进。现进入桌宠模式强制使用可无人值守的自动代理/智慧代理（自动代理按优先级决策，智慧代理AI决策失败自动回落），全节点自动推进。
- 拖动漂移：原渲染层 mousemove + setPosition 方案在窗口移动后收到坐标漂移的伪事件，按住不动时桌宠持续向右下滑动。重写为主进程驱动——按下时记录光标与窗口偏移，主进程每16ms读取全局光标位置移动窗口，渲染层伪事件不再参与坐标计算。
- 右键菜单显示不全（二次修复）：上一版 CSS max-height 修复无效的真因——菜单初始按折叠高度定位，展开后底部超出窗口被裁切且顶部不回弹。现改为扁平菜单（无展开态）+ 渲染后测量实际尺寸并将位置钳制在窗口内 + 内部滚动。

## 其他
