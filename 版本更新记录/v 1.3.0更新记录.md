# v 1.3.0 更新记录

> 新增应用内更新检查：从 GitHub Releases 自动获取最新版本信息，支持手动下载。

## 新增

### 应用内更新检查（GitHub Releases）

- 设置界面新增「版本与更新」面板：
  - 显示当前版本号；
  - 「检查更新」按钮：从 GitHub Releases 拉取最新发布版信息，比较版本号并展示结果（已是最新 / 发现新版本）；
  - 发现新版本时展示发布日期与完整更新说明，并提供「前往下载」按钮，跳转系统浏览器打开 GitHub 发布页手动下载安装包；
- 打包版启动后 30 秒静默检查一次更新：发现新版本时，主菜单「系统设置」按钮显示脉冲红点提示；
- 开发模式（`npm run dev`）不触发启动静默检查，避免开发期误报，手动检查不受限。

## 其他

- 版本号 v1.2.0 → v1.3.0（功能性更新）。
- 主菜单版本标识改为动态读取应用版本（`// SIGNAL LAB · PROTOCOL TERMINAL v{version}`），不再硬编码。
- 项目开源：仓库迁移至 GitHub（AGPL-3.0 许可证），补齐 README、LICENSE、.gitattributes 等开源仓库文件；游戏内更新检查地址指向 GitHub Releases。
