# v 0.1.0 更新记录

首个版本记录。本次为需求确认后的设计文档落盘：将已确认的核心决议写入机制文档，修复文档硬伤，并建立首版内容集。

## 新增

- 新增《干员与武器》：4名干员、4件武器的首版设计与占位数值。
- 新增《虚质图鉴》：虚质生成与成长规则、9个普通虚质模板、3个BOSS。
- 新增《转译器图鉴》：11个普通转译器、3个核心转译器、9个BOSS专属高阶转译器。
- 新增《特殊骰子图鉴》：6类特殊骰子类型、10颗具体特殊骰子、脆弱与屏障术语定义。
- 《战斗》新增：每回合双方各抽1颗骰子的明确规则、双方各行动一次、纯点数骰子无行动效果、回合阶段待定标记。
- 《骰子机制》新增：抽取与结算规则、基础骰子点数缩放公式（效果系数 = 0.5 + 点数/12）、攻击/护盾/治疗骰子的结算方式（含护盾固定持续2回合初版值）。
- 《游戏玩法》新增：纯无限模式定义、战斗间生命延续与每场战斗后自动回复（初版10%）。
- 《心理伤害》新增：心理损伤单向性（仅我方对敌方施加，干员无心理损伤累计）、心理损伤不参与伤判结算的界定、麻痹无持续时间限制的澄清。
- 《基本公式》新增：附加攻击力定义、伤害倍率与治疗倍率的作用位置澄清。

## 调整

- 《数值》修饰器叠加规则改写：负向直接乘算统一以百分比变动（如-0.3）参与加算汇总，删除与公式矛盾的"补正为原数值+1"表述；明确最终乘算以乘数形式（t=1.1）逐项相乘。
- 《心理伤害》PS改写：移除"技能"表述（本作行动均由骰子决定），改为麻痹期间跳过行动。
- 《基本公式》属性来源引用由不存在的《游戏数据基础》改为《数值》属性计算器。

## 修复

- 《伤判效果》第5行断句补全（"因此会"）。
- 《伤判效果》移除对不存在角色"陈"的引用，改为通用示例。
- 《数值》ADDTION拼写修正为ADDITION。
- 《基本公式》移除对不存在文档《定点数与浮点数》的引用。

## 其他

- 所有内容数值均为初版占位，待原型实测后统一调优。
- 待定项：回合阶段钩子（回合开始/结束等结算点）、商店详细内容与单线节点分布规则、自动回复比例与护盾持续回合数终值、麻痹层数差异与解除手段、脆弱叠加方式、附加攻击力的来源规范。
