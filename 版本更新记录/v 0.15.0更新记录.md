# v 0.15.0 更新记录

桌宠模式重构为透明桌面悬浮窗；新增好感度系统；发放 1000 算力币。

## 新增

- 桌宠模式全新呈现（独立透明悬浮窗）：
  - 进入桌宠模式后主窗口完全隐藏，游戏在后台继续自动推进（主窗口禁用后台节流，计时器不受影响）；
  - 屏幕右下角出现无边框透明悬浮窗，仅显示桌宠立绘（200px，状态驱动）与消息气泡，置顶于所有窗口之上、不占用任务栏；
  - 气泡实时显示当前活动：正在推进·第X层 / 正在战斗 / 正在与BOSS激战 / 正在决策（AI智慧代理）/ 正在选择行动 / 正在购物 / 战斗胜利 / 行动结束等；
  - 左键点击桌宠：傲娇互动（台词+好感+1）；左键按住拖动：移动悬浮窗位置；右键桌宠：操作菜单——查看饱食度、查看好感度、购买食物（25币/份）、喂食、更换自动协议（含未启用/自动协议/自动代理/智慧代理）、更换桌宠、返回大屏模式；
  - 桌宠窗意外关闭（Alt+F4）自动恢复主窗口并退出桌宠模式。
- 好感度系统：喂食 +2、点击互动 +1、每场战斗胜利 +1，上限100；桌宠窗右键菜单可查看，喂食/互动反馈中同步显示。
- 主进程桌宠窗 IPC：状态推送（pet:push）、动作转发（pet:action）、拖动移动（pet:move/bounds）；渲染层新增 petBridge（主窗口侧活动文案与状态机推送）与 petWindow（悬浮窗 UI）。

## 调整

- 小窗模式说明更新：桌宠模式描述改为"桌面悬浮窗"形态；原窗口内桌宠布局（mp-stage）已移除，常规小窗保持信息中枢布局不变。
- 结算界面在桌宠模式下不再渲染极简结束画面，改由桌宠气泡显示"行动结束 · 算力币 +X"。
