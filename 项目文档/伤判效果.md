# 伤判效果

伤判效果 是对一类通常在 计算完防御/法术抗性 后 增加或减少伤害或直接让伤害归零的BUFF的统称。且不包括无敌与重设伤害效果。

相比其他效果，伤判效果的处理顺序存在特殊的优先级，因此需要单独规定其处理流程。

目前游戏内共有7种通常是伤判效果的效果（也存在不为伤判效果的情况）：

伤害修改 : 包括脆弱、庇护、屏障（屏障量＜伤害时）、敌方的“特定条件下伤害减少”等。

过量治疗 : 包括超出生命值上限的治疗转化为屏障、超出生命值上限的治疗转化为伤害等。

抵挡 : 包括护盾（次数盾，每层抵挡一次完整伤害）、屏障（屏障量≥伤害时）、概率伤害抵挡等。

闪避 :物理闪避、法术闪避、心理损伤闪避、心理伤害闪避、真实伤害闪避、全伤害闪避等。

※单从伤害规避的角度来说闪避与抵挡是“相同的”，但实际上是两种不同的效果，这在一些判定条件中尤其明显。

不受伤 : “受到伤害时不受伤...”能力，可以被理解为没有任何原因“不受伤就是不受伤”的效果。

反伤 : 对攻击来源造成伤害的能力。

反击：受到攻击时进行额外行动的能力。

处理时，将依次按照事件优先级与BUFF的获取顺序为顺序处理每个伤判效果。（事件优先级＞获取顺序）

七类伤判效果的事件优先级从高到低为：

**不受伤 → 闪避 → 伤害修改 → 抵挡 → 过量治疗 → 反伤 → 反击**

即：先判定伤害能否被完全取消（不受伤、闪避），再对剩余伤害进行数值修改（伤害修改），随后由护盾/屏障进行吸收（抵挡，吸收的是修改后的伤害值），过量治疗仅在治疗结算管线中生效，最后结算反馈类效果（反伤、反击）。同一优先级内按BUFF获取顺序处理。

每个伤判效果需要单独处理自己的条件与效果，检查该伤害与受击单位本身是否满足其伤判条件进行伤害的修改，只有当条件满足时才可正常规避/增加/减免伤害。（如血量要求、触发概率、应对伤害类型、屏障量、护盾次数等）

若伤害被某一效果成功归零/取消（如成功闪避、成功格挡、伤害减少至0），后续一部分伤判效果（如各类检测伤害予以闪避的效果、各类计次格挡效果）将不会继续处理，绝大部分效果（例如反伤、反击、受伤计数等）仍可处理。

若所有伤判效果均被处理且伤害没有归零，则本次伤害才能被视为成功造成伤害，才可以正常享受 成功造成伤害时 节点的效果。

反之，若伤害在处理完成前归零/取消，则根据伤害情况的不同（成功抵挡/成功闪避），触发对应情况的效果（例如各类“成功闪避时”触发的效果）。

具有无视闪避能力的攻击会在处理伤判效果前赋予此次伤害“无法因闪避而取消”的效果，这种情况下仍会判定闪避效果的概率、次数等，但各种意义上都无法被闪避取消。

一个单位拥有多个闪避效果且不拥有其他类型的伤判效果时，最终的闪避成功率可视为叠乘。
