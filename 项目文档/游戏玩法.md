# 游戏玩法

本游戏的主要战斗玩法为肉鸽无限流。采用回合制战斗。

游戏为单线行动，在行动线上有普通战斗、BOSS战斗、商店、特殊事件、奖励关。普通战斗自动推进，其他节点需要玩家选择行动或进行购买或选择奖励。

本游戏采用纯无限模式：一局游戏没有终点，直到干员死亡为止，以推进层数与击杀数计成绩，难度随推进深度递增。

行动线以5层为一个循环段，固定结构为：战斗 → 战斗 → 特殊节点 → 战斗 → BOSS。特殊节点按段轮换，顺序为：特殊事件 → 商店 → 特殊事件 → 奖励关，每4段（20层）完成一轮换。

战斗之间干员生命值延续，每场战斗结束后自动回复最大生命值的一小部分（初版为10%，待调优）；商店与特殊事件提供额外恢复手段。

每次普通战斗结束后，自动获得通量奖励，BOSS战斗结束后可在3种高阶转译器中选择一个获取。

我方角色命名为干员，敌方角色命名为虚质。

我方开局前选择角色和武器。角色提供特殊能力、生命值和攻击力，武器提供初始骰子、特殊效果和攻击力。

敌方由系统生成，只有角色提供特殊能力（可以没有）、生命值、初始骰子、攻击力。

肉鸽的局内货币为“通量”，可以在商店“通量转换”中消费。同样可能在特殊事件“随机数”中的某些选项中花费。

局内的藏品系统为“转译器”。转译器只要持有就会发挥作用，部分转译器可叠加，部分不可叠加。可叠加的转译器可重复获得，不可叠加的不会再次获得，除非该转译器因任何原因失去（售出、交换等）。商店中可购买转译器，但不能购买高阶转译器。高阶转译器只能由BOSS关卡结束后选择获取，不同BOSS可获得的高阶转译器不同。

存在特殊的转译器“核心转译器”。核心转译器除了拥有常规转译器的效果外，额外拥有核心效果。当“核心转译器”置于核心槽中时，才能触发核心效果。存在3个核心槽，可替换。所有核心转译器都不可叠加。
