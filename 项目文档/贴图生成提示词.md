# 贴图生成提示词

> 配套《贴图接口.md》使用。覆盖全部待生成贴图：干员 4 张、武器 4 张、转译器 104 张，合计 **112 张**。
> 生成后按文件名放入对应文件夹即自动生效，无需改代码。

## 通用说明

1. **尺寸**：统一 1024×1024 方图。
2. **格式**：优先透明底 PNG；工具不支持透明底时保留深青色纯底（`#0a141b`），与界面风格一致。
3. **命名**：文件名必须与提示词表中的文件名完全一致（id.png）。
4. **负面提示词**（支持负面词的工具统一使用）：

```
低画质, 模糊, 变形, 畸变, 文字, 水印, 签名, 多个主体, 复杂背景, 画面拥挤, worst quality, lowres, blurry, deformed, text, watermark
```

5. **英文风格基**（英文工具可替换各提示词的风格尾句）：
   - 干员：`official mobile game character art, anime style, cel shading, clean lineart, full body standing, centered, dark teal gradient background with subtle grid, 1024x1024`
   - 道具：`single centered sci-fi tech artifact game icon, dark signal-lab aesthetic, glowing accent, cel shading, clean thick outline, 1024x1024`

6. **光效色系约定**（与游戏 UI 稀有度配色一致）：

| 分类 | 光效主色 |
|---|---|
| 普通转译器 / 基础道具 | 翠绿色（#3ee08f） |
| 核心转译器 | 琥珀金（#f0b34a） |
| 高阶转译器 | 紫罗兰（#9d8cff） |

## 设计思路备注

- **干员**：延续缪尔赛思的日系赛璐璐立绘风格；四名干员按能力差异化设计——基准（稳定绿环）、偏移（相位残像+全息骰）、溢出（紫能裂纹过载）、奇偶（校准目镜+修正骰子）。
- **武器**：统一以六边形科技骰子为母题，按武器特性区分——标准（整齐阵列）、重核（厚重金属+重力波）、干涉仪（干涉条纹）、涟漪（水面同心波）。
- **转译器**：每枚图标对应其功能语义（如"内存泄漏"=滴漏的存储罐、"尾递归"=螺旋光链、"贪婪采样"=抓取代币的机械爪），保持道具图标语言统一；稀有度通过光效色系区分，与游戏 UI 配色一致。
