# 贴图接口规范

> 接口实现：`src/renderer/src/data/images.js`
> 贴图根目录：`src/renderer/src/assets/`

## 目录结构

```
assets/
├── pets/                      # 桌宠贴图（每桌宠独立文件夹）
│   └── muelsyse/              # 桌宠id为文件夹名
│       ├── Muelsyse-full.png            # 全身立绘（图鉴/展示用）
│       ├── Muelsyse-chibi.png           # Q版·常态
│       ├── Muelsyse-chibi-happy.png     # Q版·高兴
│       ├── Muelsyse-chibi-dispirited.png# Q版·沮丧
│       ├── Muelsyse-chibi-query.png     # Q版·疑问
│       ├── Muelsyse-chibi-earnest.png   # Q版·认真
│       ├── Muelsyse-chibi-ponder.png    # Q版·思索
│       ├── Muelsyse-chibi-hunger.png    # Q版·饥饿
│       ├── Muelsyse-chibi-cry.png       # Q版·哭泣
│       ├── Muelsyse-chibi-dizziness.png # Q版·晕倒
│       └── Muelsyse-chibi-tsundere.png  # Q版·傲娇
```

## 核心规则

1. **文件名即 id**：除桌宠外的所有贴图，文件名（不含扩展名）必须与内容定义中的 id 完全一致。放入文件后**无需修改任何代码**，构建时自动收集并在对应界面展示。

2. **尺寸规格**：统一 **1024×1024**。界面按需缩放显示，不会出现大图占满版面的情况。

3. **格式支持**：`.png`、`.jpg`、`.`.jpeg`、`.webp`（推荐 PNG 透明底）。

4. **桌宠文件夹规则**：桌宠贴图因含多状态立绘，采用 `<桌宠id>/` 子文件夹组织。新增桌宠时在 `data/pets.js` 的 `PET_DEFS` 中定义并导入各状态图（当前桌宠状态图仍为显式 import，见 pets.js 顶部）。

## 合法文件名对照

| 分类 | 文件名 | 对应内容 |
|---|---|---|
| 干员 | `baseline.png` | 基准·稳态执行者 |
| 干员 | `offset.png` | 偏移·相位观测者 |
| 干员 | `overflow.png` | 溢出·过载写入者 |
| 干员 | `parity.png` | 奇偶·低值修正者 |
| 武器 | `standard.png` | 标准协议骰组 |
| 武器 | `heavy.png` | 重核骰组 |
| 武器 | `interferometer.png` | 干涉仪骰组 |
| 武器 | `ripple.png` | 涟漪骰组 |
| 转译器 | `<转译器id>.png` | 全部转译器id见 `data/translators.js` 或游戏内图鉴→转译器页 |

## 调用接口

```js
import { characterImg, weaponImg, translatorImg } from '../data/images.js'

characterImg('baseline')      // → 图片URL（无贴图返回 null）
weaponImg('heavy')
translatorImg('assertModule')
```

返回值为打包后的资源 URL（Vite 会处理哈希与拷贝）；未提供贴图时返回 `null`，界面按"无图"样式渲染，不会报错。

## 当前展示位置与显示尺寸

| 位置 | 分类 | 显示尺寸（小窗模式） |
|---|---|---|
| 图鉴→干员 | 角色 | 76px（56px） |
| 图鉴→武器 | 武器 | 76px（56px） |
| 图鉴→转译器 | 转译器 | 56px（44px） |
| 桌宠终端/主菜单/小窗/悬浮窗 | 桌宠 | 各界面固定（见 pets.js 引用处） |

新增展示位时：调用对应 `xxxImg(id)`，为空时用条件渲染跳过 `<img>` 即可；CSS 统一使用 `object-fit: contain` 保持比例。
