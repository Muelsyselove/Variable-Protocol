# 战斗

我方和敌方1v1回合制战斗。我方和敌方在基础情况下最多持有10个骰子。

战斗时，每回合双方各从自己的骰池中随机抽出1颗骰子（骰子为独立实例，系统需追踪具体被投出的是哪一颗，详见骰子机制）。抽出骰子点数较大的一方先行动；点数相同时，重新掷骰子，并以最新的一次结果为准。

双方每回合各行动一次，仅行动顺序不同。行动时，根据抽出的骰子造成效果（点数与效果数值的关系详见骰子机制）。

任意一方生命值归零时，如果没有锁血、复活等效果，视为战斗结束。

## 回合阶段

每个回合按以下五个阶段依次进行：

1. **回合开始**：按顺序结算——心理崩溃效果的持续时间-1（归零则移除该崩溃效果）；临时骰子的剩余持续回合-1（归零则从骰池移除）；各类"每回合"效果结算（如持续伤害、每回合屏障/护盾等）。护盾（次数盾）与屏障（数值盾）均无持续时间，不会因回合流逝而消失。
2. **掷骰**：双方各从自己骰池随机抽出1颗骰子，点数大者获得先手；平局则重掷，以最新结果为准。拥有麻痹层的单位在此阶段消耗1层麻痹，跳过本回合掷骰与行动，对方自动获得先手（详见心理伤害）。
3. **先手方行动**：按抽出骰子的类型结算行动效果。"行动时受到伤害"类效果在该单位行动结算前触发。
4. **后手方行动**：同上。
5. **回合结束**：清理本回合的临时状态。

"受到攻击时"类效果在对应攻击的伤判效果结算完成后触发。
