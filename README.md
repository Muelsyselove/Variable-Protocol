# 变量协议 Variable Protocol

回合制骰子肉鸽 · 无限流协议决斗

在信号实验室的废弃协议层中逐层深入，用骰组与转译器对抗失控的变量实体。每一步判定都掷骰，每一件转译器都改写你的概率——构建属于你的协议，直到递归终止。

## 特性

- **回合制骰子决斗**：攻击、防御、屏障、干涉等多种功能骰，掷骰判定驱动战斗
- **转译器构筑**：收集数十种转译器，改写骰点判定规则，组合出流派
- **干员与武器**：多干员多骰组开局选择（标准/重核/干涉仪/涟漪）
- **地图事件**：商店、事件、奖励关、BOSS 层构成的无限流行动线
- **AI 自动代理**：接入任意 OpenAI 兼容接口，AI 实时代理决策、自动推进对局，支持自定义协议方案与「进化模式」
- **桌宠终端**：桌宠模式挂机推进对局，饱食度、好感度、喂食互动一应俱全
- **档案图鉴**：骰子、转译器、特殊骰、虚质的 3D 与插画档案

## 下载与安装

前往 [Releases](https://github.com/Muelsyselove/Variable-Protocol/releases/latest) 下载最新 Windows 安装包（`VariableProtocol-Setup-x.x.x.exe`）：

1. 运行安装包，可自选安装位置，可选创建桌面/开始菜单快捷方式
2. 升级安装自动保留存档（用户数据存于 `%APPDATA%\变量协议`）
3. 游戏内「系统设置 → 版本与更新」可检查新版本并跳转下载

## 从源码运行

需要 Node.js 18+：

```bash
npm install        # 安装依赖
npm run dev        # 开发模式
npm test           # 冒烟测试
npm run dist       # 构建 Windows NSIS 安装包（输出至 dist/）
```

## 更新机制

游戏内置轻量更新检查：启动后静默请求 GitHub Releases 最新发布版接口，与当前版本号比较；发现新版本时在主菜单设置入口显示红点，设置页可查看更新说明并一键跳转发布页手动下载。不做自动安装，下载与安装始终由用户手动完成。
